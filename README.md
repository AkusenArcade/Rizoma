# Rizoma

A file manager for Linux, built on [Genoma](../Genoma) and part of the
[Bioma](../Bioma) ecosystem.

A rhizome is an underground stem that branches, stores reserves and grows a
new shoot from any of its nodes — folders, files and links. Bioma, Genoma,
Rizoma.
