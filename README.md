# Rizoma

A file manager for Linux, built on [Genoma](../Genoma) and part of the
[Bioma](../Bioma) ecosystem.

A rhizome is an underground stem that branches, stores reserves and grows a
new shoot from any of its nodes — folders, files and links. Bioma, Genoma,
Rizoma.

Status: it browses, searches, previews, copies, moves, renames, makes folders
and has the trash. See [`docs/plan.md`](docs/plan.md).

```
./install.sh             # for this user; --here runs it from this checkout
rizoma [folder …]        # each in a tab
```

To open folders with it everywhere, turn DEFAULT on in the cell of the button at
the foot's right.

It needs a Genoma newer than 0.1.24.
